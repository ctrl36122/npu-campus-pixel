这个包没有 Apple 开发者签名，Apple 芯片上未签名的程序会被系统直接拦掉。 解压之后先在「终端」里跑一次（只跑一次），之后双击就能玩： 
cd ~/Downloads
xattr -cr 像素工大.app && codesign --force --deep --sign - 像素工大.app
放在别处就把第一行换成对应目录（~/Desktop 或 ~/Applications）。包内还有一份「macOS 安装说明.txt」。

所有客户端连同一个公共服务器（<你的服务器IP>）， 只有连同一台服务器、并且进同一层同一间宿舍的人才能互相看见。
进宿舍楼按 E，认房间 / 写公告板 / 躺床也都是 E， 按 P 打开好友面板，T 打开传送面板，Tab 改昵称与服务器地址。

v1.2.3 修了聊天：以前发完一条消息，输入框里的字不会清掉，再按一次回车就把同一句又发一遍； 而且客户端发的话会被转发两次，别人那边看到同一条消息刷两遍。现在发完即清空，每条消息只显示一次。
v1.2.2 加了宿舍门禁：每间房的门会滑动开关，只有房主和房主的好友能把门打开， 其他人走到门口会被挡住（门口地上会有提示）。想进别人的房间就按 P 申请加好友， 对方同意后就能自由进出。
这两版都碰到联机协议，客户端和服务端必须都是同一版，旧客户端连新服务器会进不去。 服务器已经是最新的，装最新客户端即可。
下载后建议核对 SHA-256
文件现在托管在 GitHub Releases，走的是 https；但如果你用的是某个第三方镜像， 仍建议本地算一次哈希对照，确认下来的就是原始文件。 Windows 用 PowerShell： 
Get-FileHash .\XGD-Campus-win64.zip -Algorithm SHA256
macOS / Linux： 
shasum -a 256 XGD-Campus-macos.zip
