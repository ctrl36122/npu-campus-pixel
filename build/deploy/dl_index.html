一款主打多人联机的像素校园——和大家在同一个西工大里逛，路上随时能碰到人。

· 实时同屏：进游戏就能看到其他在线的同学，位置实时同步，校园里直接偶遇。
· 约人组队：组队板发个招募，喊人一起玩、约在某个楼下集合。
· 聊天：世界频道喊话，也能私聊，不打扰别人；聊天有敏感词过滤。
· 宿舍门禁 + 好友：每间房的门只有房主和其好友能开。想进别人的房间，按 P 申请加好友，对方同意后自由进出。
· 一起养猫：校园猫的领养记录存在服务器上，大家养的是同一批猫。

所有客户端连同一个公共服务器（地址在客户端按 Tab 可查可改），手机、电脑都连同一个服。 进宿舍楼按 E，认房间 / 写公告板 / 躺床也都是 E， 按 T 打开传送面板，Tab 改昵称与服务器地址。

v1.2.6 新东西：宠物能用了 —— 可以改名、可以牵着遛， 猫跟在你身后约 3 格，落后了会自己追上来，不会掉到屏幕外，也不会在脚边抽搐； 手机右下多了一块「交互牌」（走到门 / 椅子 / 猫旁边才出现，点一下等于按 E）， 聊天小窗收小贴到左上角，不再挡半个屏幕；另外几栋楼的屋顶、幕墙和广场雕塑按实景重做了一轮。
走动的声音也重做了：草地、沥青路、石板广场、室内木地板各是一套音色， 踩在不同地面上能听出区别；原先室内木地板比其他地面响一大截，现在已经压平。
v1.2.5 换上了现实里西安的实况天气，晴 / 阴 / 雨 / 雪四态平滑过渡，雨丝随风倾斜、落地有水花、路面泛起涟漪； 宿舍北墙开了落地窗，玻璃真透明、透出窗外那片天和远山，家具换成一套新的顶视图集、四款布局轮换。
v1.2.4 补上了运动场地（8 块球场按 OSM 真实轮廓绘制，围网与投光灯齐全），水域能划船（岸边按 E 上船，方向键划水）。

版本兼容：v1.2.6 没有改联机协议，和服务端 v1.2.5 也能正常连。 v1.2.3 到 v1.2.5 之间动过协议，客户端和服务端最好是同一版； 但旧客户端（v1.2.2 及更早）连新服务器会直接连不上，必须更新。
